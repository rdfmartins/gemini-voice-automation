# Plano de Ação - Redes Sociais (Threads/LinkedIn)

## 🎬 Roteiro do Mini Vídeo
**Ferramenta sugerida:** Gravar a tela com o celular focando no terminal (ar autêntico) ou OBS Studio.
**Duração alvo:** ~15 segundos.

1. **Cena 1 (2s):** Mostrar a tela do terminal aberta em uma pasta com arquivos (ex: projeto).
2. **Ação (5s):** Digitar `augustus`, dar enter e falar (capturando o áudio): *"O que esse arquivo README faz?"*
3. **Cena 2 (3s):** Mostrar o terminal processando (listagem de arquivos injetada pelo Smart Prompting).
4. **Cena 3 (5s):** A resposta da IA aparece na tela baseada no contexto local.
